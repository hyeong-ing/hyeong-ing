# 🔹 ABOUT ME
#### • Java와 Spring을 중심으로 백엔드 개발을 공부하며 React∙Vue∙Next.js를 활용한 프론트엔드 개발도 경험하고 있습니다.
#### • 기능을 구현하는 것에서 끝내지 않고 **왜 이런 구조와 기술을 선택했는지 이해하고 기록하는 개발**을 지향합니다.
#### • 최근에는 AI 개발 도구를 실제 프로젝트 과정에 적용하고 완성된 결과를 직접 검토하며 UI∙데이터처리∙테스트까지 다시 개선하는 과정을 경험했습니다.
#### • 프로젝트를 진행하며 배운 내용과 문제 해결 과정은 [Tistory](https://post-this.tistory.com/)에 기록하고 있습니다.
